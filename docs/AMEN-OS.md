# AMEN OS

Своя прошивка для M-VAVE FM-1 под jungle, drum & bass и breakcore. Свои звук, секвенсор, интерфейс и управление.
От Felucca взят только скрытый слой железа — [felucca-bsp](../fw/firmware/bsp/) (MPL-2.0): драйверы экрана, клавиш,
энкодеров, светодиодов, аудиокодека, USB, флеша и путь обновления по USB-MIDI. Ни строки интерфейса Felucca в AMEN OS нет.

## Звук

Три дорожки, больше ничего:

| Дорожка | Движок | Что |
|---|---|---|
| **BRK A** | JUNGLE | основной брейк |
| **BRK B** | JUNGLE | второй брейк: слой, эдиты, другой брейк поверх |
| **BASS** | REESE | бас, моно, с легато и слайдами |

Мастер: даб-дилей (посыл с каждой дорожки, 1/8, 3/16, 1/4, обратная связь), DJ-фильтр (одна ручка: влево ФНЧ, вправо
ФВЧ), лимитер. Все движки, сэмплы и эффекты Felucca убраны.

## Секвенсор

- 8 **сцен** A–H; сцена — это паттерны всех трёх дорожек. Длина 16 или 32 шага (1 или 2 такта).
- Переключение сцены во время игры ждёт конца такта.
- **Шаг брейка:** слайс (00–31), **ROLL** x1–x4, **CHANCE** 100 / 75 / 50 / 25 %, **FX** шага:
  - `--` — как есть;
  - `REV` — слайс задом наперёд;
  - `UP` / `DN` — питч ±12 на одном шаге;
  - `CUT` — оборвать на половине шага.
- **Шаг баса:** нота, **TIE** (тянуть дальше), **SLIDE**, **ACCENT**.
- **Свинг** — общий.

## Управление

Напечатанная кнопка → что она делает в AMEN OS:

| Кнопка | Нажать | Держать |
|---|---|---|
| **PLAY** | старт / стоп (стоп дважды — в начало) | |
| **REC** | запись с клавиш в играющие шаги | |
| **HOME** | экран MAIN | |
| **SEQ** | экран STEP (шаги текущей дорожки) | |
| **EDIT** | экран SOUND (звук текущей дорожки) | |
| **FX** | экран FX (дилей, фильтр) | |
| **GLO** | экран SET (темп, свинг, длина) | |
| **ENV** | **MANGLE**: новый эдит текущей дорожки в выбранном стиле | |
| **ARP** | | **REPEAT**: бит-репит брейков; белые клавиши 1–4 — 1/4, 1/8, 1/16, 1/32 |
| **LFO** | | **TAPE STOP**: всё замедляется до остановки, отпустил — разгоняется |
| **SCL** | мьют текущей дорожки | |
| **SAVE** | сохранить проект во флеш | |
| **OCT− / OCT+** | страница: такт шагов, страница звука, окно слайсов / октава баса | обе 5 с — режим обновления |

Ручки:

| Ручка | Что |
|---|---|
| **SELECT** | дорожка: BRK A / BRK B / BASS |
| **ALGORITHM** | сцена A–H (во время игры — с конца такта) |
| **PRESETS** | пресет звука текущей дорожки |
| **K1–K4** | параметры экрана (подписаны внизу экрана) |
| **MASTER** | громкость |

Клавиши:
- **MAIN, SOUND, FX, SET:** играют текущую дорожку. На брейке клавиша — слайс, на басе — нота.
- **STEP:** 16 белых клавиш — шаги такта. Нажатие включает или выключает шаг и выбирает его для ручек K1–K4. Подсветка клавиш показывает шаги, бегущий огонёк — играющий шаг.

## Экраны

- **MAIN** — сцена, темп, три дорожки полосами шагов с бегущей позицией, мьюты, стиль MANGLE. K1–K3 — громкости дорожек, K4 — DJ-фильтр.
- **STEP** — шаги текущей дорожки крупно, выбранный шаг и его параметры.
- **SOUND** — восемь параметров движка (две страницы) и картинка звука: карта брейка или биения риза.
- **FX** — посыл дилея текущей дорожки, время, обратная связь, DJ-фильтр.
- **SET** — темп, свинг, длина, MIDI-канал.

Свой пиксельный шрифт, своя тема.
